# Locale, direction and time zone

`I18nProvider` gives the parts inside it a locale and its direction. It renders only its children, so put `lang` and `dir` on an element yourself.

```brm
<script>
  import { $signal } from 'brumate/signals';
  import Button from '@brumate/ui/Button.brm';
  import I18nProvider from '@brumate/ui/I18nProvider.brm';
  import Label from '@brumate/ui/Label.brm';
  import Meter from '@brumate/ui/Meter.brm';

  const locales = ['en-US', 'de-DE', 'ar-EG'];
  let locale = $signal('en-US');
</script>

#for (item of locales by item) {
  <Button onPress=(() => (locale = item))>{item}</Button>
}
<I18nProvider {locale}>
  <div dir=(locale === 'ar-EG' ? 'rtl' : 'ltr') lang=locale>
    <Meter value=(1234.5) maxValue=(5000) formatOptions=({ style: 'unit', unit: 'megabyte' })>
      <Label>Used</Label>
    </Meter>
  </div>
</I18nProvider>
```

- `locale` is a language tag. The default is `en-US`, so the server and the browser format numbers the same way. It can change at run time, and the parts that format with it show the new format.
- The direction comes from the script of the locale. A `Toolbar` turns its arrow keys around right to left, and a `Popover` reads `start` and `end` in it.
- `timeZone` is an IANA time zone, such as `Asia/Tokyo`. It decides what today is in the date parts. Without it, the server uses its own zone for the first render and the browser takes its own after that.
- A part outside an `I18nProvider` uses `en-US`.

## Date strings

The date parts read their words from the locale: the placeholders of the segments, the names of the segments for screen readers, and the labels of the `Calendar` and the `DatePicker`. English, German, French, Spanish, Japanese and Chinese (Simplified, and Traditional for `zh-Hant`, `zh-TW`, `zh-HK` and `zh-MO`) have a table. Another language shows English words.

The server writes only the table of the active language into the page. To use your own words, pass the whole set as `strings`, and start from `getDateStrings` to change a few:

```brm
<script>
  import I18nProvider from '@brumate/ui/I18nProvider.brm';
  import Button from '@brumate/ui/Button.brm';
  import { getDateStrings } from '@brumate/ui/date-strings.ts';

  const strings = { ...getDateStrings('de-DE'), previous: 'Früher', next: 'Später' };
</script>

<I18nProvider locale="de-DE" {strings}>
  <Button>Weiter</Button>
</I18nProvider>
```

The keys are `placeholders`, `segmentNames`, `empty`, `previous`, `next`, `calendar`, `today`, `selected`, `firstAvailable` and `lastAvailable`. `today`, `selected` and the availability labels take `{date}`.

- Numbers (`NumberField`, `Meter`, `Slider`) format with the locale and `formatOptions` (an `Intl.NumberFormat` options object).
- Words that are not in a date part, such as the label of a `Button`, are yours: translate them in your page.
