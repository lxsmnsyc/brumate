# @brumate/language-server

The language server for brumate `.brm` files. It works in any editor that speaks the Language Server Protocol. It gives the errors and warnings of the compiler, and completion, hover and errors for styles in CSS, SCSS and Less. Start it with `brumate-language-server`. The VS Code extension runs it. Types, completion and go to definition for the TypeScript in `.brm` files come from [`@brumate/typescript-plugin`](../typescript-plugin).

Part of [brumate](https://github.com/lxsmnsyc/brumate), a component language and compiler for resumable web apps.
