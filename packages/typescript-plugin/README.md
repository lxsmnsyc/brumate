# @brumate/typescript-plugin

A TypeScript server plugin. Editors that use the TypeScript server check `.brm` files with it. `.ts` files that import them get the props of each component. It needs TypeScript 5.0 to 6: TypeScript 7 does not load plugins.

Part of [brumate](https://github.com/lxsmnsyc/brumate), a component language and compiler for resumable web apps.
