Breaking for code that provides or reads these contexts itself. The last contexts that changed through the live context path now hold stores. `LocaleContext`, `DateStringsContext`, `TextContext`, `SelectionIndicatorContext`, `TransitionContext`, `TokenContext`, `ColumnContext`, `TreeRowContext`, `VirtualizerContext` and `ToastRegionContext` hold a `StoreLike` of the value they held. `ButtonContext` and `LinkContext` hold `{ state, handlers }`: `state` is a `StoreLike` of the props that are not functions, and `handlers` is a props value or `{ slots }` of the `on...` functions, with the same slot names. `CheckboxGroupContext`, `RadioGroupContext`, `ToggleGroupContext`, `DisclosurePanelContext`, `DisclosureGroupContext`, `OverlayTriggerContext`, `DialogContext`, `SliderContext`, `TagGroupContext`, `TokenFieldContext`, `TabsContext` and `TooltipTriggerContext` hold `{ state, ...handlers }` with the functions (`toggle`, `select`, `open`, `close`, `expand`, `setThumb` and so on) as optional keys beside the store. The state types lost their function members. Type a custom provider against the new `ButtonGiven`, `LinkGiven`, `CheckboxGroupGiven`, `RadioGroupGiven`, `ToggleGroupGiven`, `DisclosurePanelGiven`, `DisclosureGroupGiven`, `OverlayTriggerGiven`, `DialogGiven`, `SliderGiven`, `TagGroupGiven`, `TokenFieldGiven`, `TabsGiven` and `TooltipTriggerGiven`, and the matching `...Handlers` types. `ButtonStateProps`, `LinkStateProps` and `ButtonHandlers` split `ButtonContextProps` and `LinkContextProps`, and `slotHandlers` reads the handlers of a slot. A plain value now throws "gives no store". To migrate, provide with `$setContext(Ctx, { state: $toStore(memo), onPress })` and read with `const given = $getContext(Ctx); const value = $store(given.state);`. For `ButtonContext`, move the functions of each slot to `handlers: { slots: { name: { onPress } } }`. To clear a context for the parts inside, provide `{ state: store(null) }`, or `store(null)` for a context that is a store alone.

`LocaleContext` holds `null` outside an `I18nProvider`. `DEFAULT_LOCALE` (new export of `locale.ts`, `en-US`) is the fallback, so a custom reader does `$store($getContext(LocaleContext, store(DEFAULT_LOCALE))) ?? DEFAULT_LOCALE`.
