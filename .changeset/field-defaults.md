'brumate': patch
---

- A field of markup that resumes after a write, such as markup that streams in, keeps what the user did before its code loaded, such as a box that the user checked. Before, the first update of its scope put back the server's value.
- A module function that returns one local under two keys, such as `{ up, cancel: up }`, is a compile error that says so. Before, the second key was a copy of a function, which failed when the page state was sent.
