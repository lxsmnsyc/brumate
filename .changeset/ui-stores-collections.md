Breaking for code that provides or reads these contexts itself. `ListBoxContext`, `ListBoxGivenContext`, `CollectionFocusContext`, `MenuContext`, `MenuTriggerContext`, `SubmenuContext`, `TableContext`, `TableResizeContext` and `TreeContext` hold `{ state, ...handlers }`: `state` is a `StoreLike` of the data they held before, and the functions (`select`, `action`, `setActive`, `closeAll`, `sort`, `toggle` and so on) are optional keys beside it. `SelectValueContext`, `FieldInputContext`, `NavigationTreeContext` and `NavigationLinkContext` hold a `StoreLike` of the value they held. The state types (`ListBoxState`, `ListBoxGiven`, `CollectionFocus`, `MenuState`, `MenuTriggerState`, `SubmenuState`, `TableState`, `TableResizeState`, `TreeState`) lost their function members, which are now `ListBoxHandlers`, `ListBoxGivenHandlers`, `CollectionFocusHandlers` and keys of `MenuGiven`, `MenuTriggerGiven`, `SubmenuGiven`, `TableGiven`, `TableResizeGiven` and `TreeGiven`. Type a custom provider against `ListBoxProvided`, `ListBoxGivenProvided`, `CollectionFocusProvided`, `TableGiven`, `TableResizeGiven`, `TreeGiven`, `MenuGiven`, `MenuTriggerGiven` and `SubmenuGiven`. A plain value now throws "gives no store". To migrate, provide with `$setContext(Ctx, { state: $toStore(memo), onPress })` and read with `const given = $getContext(Ctx); const value = $store(given.state);`. To clear a context for the parts inside, provide `{ state: store(null) }` (or `store(null)` for the four plain ones).
