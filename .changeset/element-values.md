The element types of `brumate/elements` accept every value that the runtime accepts: `class` as an array or an object, `style` as an object, `value` on `select`, a binding for `value` and `checked`, a server function for `action` and `formaction`, a numeric string for number attributes, and a boolean for `autocomplete`. `onKeyPress` exists, the broken `onToggleEnd` is gone, and `EventHandler`, `ClassValue`, `StyleObject` and `ServerFunction` are exported.
