# Log: ui-date-i18n

- Probe: `I18nProvider` sets `LocaleContext` with `{ locale, direction }`. The parts read it with `$getContext` and the server render uses the same value, so the locale reaches the HTML with no extra step.
- A `$getContext` value counts as "can change on the client", so any part that reads strings from the context ships the code that reads them. The table must not be looked up in a part. `I18nProvider` looks it up (`stringsOf`) and sets `DateStringsContext`. With a literal `locale` the provider ships no client code, and the German strings travel only as page state. Checked with `brumate inspect` and by grepping a built bundle for `Zurück` and `jjjj` (none).
- Outside an I18nProvider the context holds null and each part falls back to its English words. A default context value of the English object cost about the same bytes, and a table in the context default would have pulled `stringsOf` into the client.
- `$effect` never runs at load. Today uses `$client(..., 'idle')` with `watchToday` in calendar.ts. The signal starts with the server's date, so the first browser render matches the HTML.
- First try of `watchToday` computed the milliseconds to midnight in the zone with `toLocaleTimeString`, capped at one hour. It cost 65 B gzip more than a timer at each minute boundary (`60_050 - Date.now() % 60_000`), which moves the date within 50 ms of midnight in every zone, DST days included. Kept the minute timer, to stay in the 0.5 kB budget.
- Keeping a `today` signal in each of DateField, DateRangePicker and Calendar cost about 0.4 kB more. Only the Calendar tracks today now. The fields start an empty segment at `todayString(locale.timeZone)`, so they follow the provider's time zone but not the browser's.
- Tests of the mocked clock fake only `Date` (`vi.useFakeTimers({ toFake: ['Date'] })`) and hold the long `setTimeout` calls by hand. Faking `setTimeout` too stops the loader and `waitFor`. A zone mismatch is made with `setLocalTimeZone` from `@internationalized/date` between the mount (server render) and the idle callback (browser).
- Size: +472 B after the review fixes (templates for the joined labels, zh-Hant). Stepping from today at key time would make it 508 B.
