# Outcome: external-scripts

## Built

- `<script src>` and `<script inline>` are markup in `#head`, in block bodies and at the top level (`packages/brumate/src/parser.ts`, `ScriptMark` in `ast.ts`). `trigger` is `idle`, `visible`, `interaction` or `load`.
- `emitElement` in `codegen/markup.ts` writes a `<script nonce>` for an untriggered script in the `#head` of the server, and `<template b-script="trigger" …attributes>` elsewhere, with the code of an inline script in an inert script inside it.
- Loader (`runtime/boot.ts`): `when` and `after` are shared with `$client` and `#defer`; `onScript` makes the script once per page by resolved `src` or code, with the nonce of the loaded page. `interaction` is for scripts only.
- Trusted Types: `trustedScript(code, true)` gives `createScriptURL` (`runtime/trusted.ts`). `runnable` in `navigate.ts` uses it for `src`, and `updateHead` compares head HTML without the nonce.
- Build flag `scripts` (`features.ts`, `runtime/features.ts`).
- Errors BRM212 to BRM216; `trigger` and `inline` typed in `elements.d.ts`.
- Docs: `website/docs/navigation.md`, `reference-security.md`, `docs/decisions.md`; changeset `.changeset/external-scripts.md` (minor).
- E2E: `e2e/suites/scripts.mjs` on the new `examples/external-scripts`. Unit tests in `packages/brumate/test/external-scripts/`.

## Proof

Not a fix node. Two bugs of the head path on a common route were fixed on the way (see Gotchas).

## Stubs left

## Gotchas

- Under a CSP with a nonce, `updateHead` never kept a head element with a nonce, since each response has its own. Fixed behind the `scripts` flag.
- A head `<script src data-rerun>` was refused under `require-trusted-types-for`. Fixed.
- The core scans markup before it is in the page, so `load` waits one microtask before it checks `isConnected`.
- rolldown keeps an import used in a branch of a flag when the test reads a property first. Put the flag first, or fold the code into an existing function.
- `visible` in a template that the browser clones watches the element after it; with none, the script runs at once.
