Two more (debounce-start, function-prop-reads) come from the refresh that patches that over.

### 4. The 20 HTML bodies

From `html-bodies.test.ts`: 14 render a `#try` in place between markers (awaitInline, cloneTemplate, cloneTry, clonedForeignTry, streamedCatchNested, tryInChildren, tryTemplateIf, tryTemplateNested, tryTemplatePropIf, tryWait, tryWaitKidHost, tryWaitLoading, tryWaitNested, tryWaitRows; 5 of them also wait in a body script); 3 are `#offscreen` (offscreen r2 and r7, offscreenInChildren); 2 are `#for` with a window (windowedChildren, windowedNested); 1 is a `#for` body whose script calls `makeId` (fields). Beside them, test/render has 97 `$$b.raw` calls (`#template` functions) and the `children` closures, which also give HTML.

clone-remaining-bodies removes the 20 bodies and the client `$$before` rewind. It does not let the runtime drop the HTML string path: templates and children still need `holdPlace`, `placed` and `parseHTML`. That is item 5.

## Gotchas

- Coverage runs with every flag on. The off path of a flag looks covered when the flag's line is reached; check the branch arms.
- `refresh(live, true)` is not dead code: deleting it breaks async memos that a browser render starts.
- A fix to `handlerProp` touches every function prop, not only setters.
- `divergences.test.ts` writes to `.output/differential-0`, as shard 0 of the differential test does; do not run both at once.

## Proposed learnings

- A divergence probe (delete DIVERGENCES, run the page as must-match) shows the exact diff of a cause in seconds | used here for all 11 causes | packages/brumate/test | no
- The render module recompiles the script with locals; new code in it that runs after the render ends must read slots, not locals | four causes come from it | packages/brumate/src/codegen | no
