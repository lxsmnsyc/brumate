# Log: dynamic-tag-types

## 2026-10-28

- Probe on main: `<{tag} onClick=((event) => event.currentTarget.focus())>` with `tag: 'button' | 'a'` gave TS7006 (implicit `any`). `href=(1)`, `foo="x"`, a wrong `ref` and `<{Toggle} bogus=(1)>` gave no error.
- Baseline, `npx brumate-tsc --noEmit --extendedDiagnostics` in packages/ui at fe61c693: 7,698,020 instantiations, 223,952 types, 270k entries in the assignability cache.
- First shape: curried `$$dynamic(tag)(attributes)` with the overloads `<T extends keyof Elements>`, `<P>(tag: Component<P>)`, `keyof Elements | Component` (global attributes) and `string`. Handlers in the object got no type for a union of names: TypeScript types no parameter from a union of signatures that differ. So a handler is written `onClick: $$handler(tag)("click", handler)`, which types `currentTarget` as the union of the elements, and passes other names through (a component types them from its prop by inference from the return type).
- Instantiations stayed at +1.5%, but the check time went from about 8 s to 16 s, with 2.0M entries in the assignability cache. Bisecting the helpers (loose versions of each) showed each helper alone cost it. Micro files: a call whose tag is `AsTarget` (a generic `T | 'div'` or the resolved union) that fails `<T extends keyof Elements>(tag: T)` costs about 16k relations and 50 ms, for each part, where `<T extends string>` fails at once (`Component` is not a string). `<T extends string>(tag: T & keyof Elements)` was cheap for a resolved union but not for a generic tag; `<T extends string>(tag: T)` was cheap for both.
- So the element overload takes any string, and the attributes come from `$$Attributes<T> = T extends keyof Elements ? Elements[T] : Record<string, unknown>`, a conditional that a declaration leaves unresolved. This also covers custom tags, so the `string` overload went away.
- A check of spread names on a dynamic tag (`$$dynamicSpread`, the mapped type of `$$spread` over `keyof $$Attributes<T>`) made 89M instantiations, from the declaration alone. Dropped: the values of a spread are checked in the object, its names are not.
- The generic form checks `Omit<GlobalAttributes<HTMLElement | SVGElement>, 'ref'>` and an index signature, with a loose `ref` (a part binds `TargetElement<T>`). An index signature only cost about 2k relations less, so the global attributes stay.
- Casts: 59 `currentTarget as` in packages/ui at the base. The handlers were named functions with `event: Event`, so a cast went away only by typing the parameter, `event: FocusEvent & { currentTarget: Element }`, which the check of each tag now verifies. 18 more wrappers that call them with plain events got the same type, found by a loop over the TS2345 errors. Handlers on a generic tag take `HTMLElement | SVGElement`, so press.brm.ts `pointerDown` takes that union and `keyUp` takes `Element`; `isAnchor` became a type guard for its `click()`. TabList keeps one cast: `moveFrom` needs an `HTMLElement`.
- New errors in packages/ui, all real: `onItemaction` (ListBoxItem, GridListItem) is a custom event that `ElementEvents` lacked, now merged in collection.ts. Group spread a rest with `'aria-disabled'?: unknown` over its own `aria-disabled`, now an ARIA value type.
- Merged origin/main (template-context-types): its passed templates write the template in place of a prop value. The dynamic tag shares that through `propValue`.
- After the merge, origin/main 81fa174b: 7,716,577 instantiations, 225,111 types, 272k relations. Head: 7,780,015 (+0.8%), 272,028 types, 334k relations (+23%). The machine was shared by other workers, so times varied from 8 s to 24 s for the same code; see the outcome for paired runs.

## 2026-10-28, review fixes

- The review found the cause of the +15%: `$$Attributes<T>`, a conditional alias over `keyof Elements` in the prelude, which TypeScript instantiates in each of about 190 generated files. The attribute types, the global attributes and the handler type moved to packages/brumate/check.d.ts, exported as `brumate/check` (types only, internal, not part of the element-types contract), and the prelude uses them by `import('brumate/check')`. tsconfig.elements.json checks the file too.
- Spreads of a dynamic tag are arguments after the object, `{...$$present(value) }` with braces that stand for the spread, so a wrong value is reported at the spread, not at `<`. A component checks its props whole without a spread, and `Partial` for the object and each spread with one, since a spread can hold required props. A tag that can be either leaves spreads unchecked (`object`): a part spreads its rest, and the attributes of a context are `Record<string, unknown>`, which fails the global handler types on its own.
- Checked alone, Dialog's `aria-label=label` failed: `label` came from the target's props, a generic `aria-${string}` type. DialogOwnProps now has `'aria-label'?: string`.
- origin/main 81fa174b against head b8497dab, packages/ui: instantiations 7,716,577 / 7,770,748 (+0.7%), types 225,111 / 235,752, assignability cache 272k / 312k. Paired check time 8.64/7.94, 7.77/7.98, 7.70/8.00 s.
- Recheck fix: a component with spreads takes `Omit<P, SpreadKeys<S[number]>> & Partial<P>` for its object, so a required prop that no spread names is reported at the tag. Fixture lines 26 to 30 show the cases.
